# Jaspr Storybook framework

Use Bun for dependencies, scripts and builds. This is a native Jaspr renderer,
not a React application. Keep application code and assets out of this repository.
The companion Dart runtime is `jaspr_storybook` in Code-Growers/jaspr_storybook.
Keep releases and browser protocol compatible. Run format, lint, typecheck,
non-watch tests, build and example verification before publication.
Use available browser tools; do not install browsers solely for verification.
